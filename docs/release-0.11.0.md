# Schema Teams Desktop 0.11.0

Д5: проверка пакетов и единый процесс установки, обновления, восстановления и
отката. Дополнительно исправлен общий вход завершения таймера без сети.

На этой контрольной точке подготовлен каталог приложения `win-unpacked`.
Установщик 0.11.0 ещё не выпущен: NSIS-упаковка требует отдельного допуска.

## Проверка и установка плагинов

Main связывает свежий каталог и зависимости, потоковую загрузку, ограниченную
распаковку ZIP, проверку всех DLL через Windows WinTrust, XML `.addin` и
транзакцию файлов. Для каждого года используется утверждённая раскладка;
имена файлов активации и GUID не назначаются каталогом или содержимым ZIP.
Кириллические пути передаются нативным XML-helper в UTF-8.

Перед обновлением отдельно проверяется владение прежним набором: байты,
раскладка, GUID, конечный Assembly и текущий доверенный издатель. Допуск всего
следующего набора требует свежих серверных метаданных, включая оставшиеся
плагины, зависимости и отсутствие циклов. Прежний receipt сам по себе не
подтверждает текущие channel, verified или requires.

Проверяется отсутствие совпадающих AddInId в чужих пользовательских и общих
`.addin` Revit 2025/2026, включая другое имя файла. Чтение ограничено числом
файлов и размером XML; неизвестная структура или невозможность чтения
блокируют действие. Проверка не загружает DLL и не запускает Revit.

Запись использует проверенные копии, журнал, fsync и замену отдельных файлов.
Откат возвращает весь прежний управляемый набор, включая удаление добавленной
зависимости. Удаляются только точные известные файлы активации. Чужие файлы,
неподдерживаемые и повреждённые журналы сохраняются. Это восстанавливаемая
транзакция; все файлы нескольких лет не становятся атомарными для Windows.

Работающий Revit или неопределённость запроса о процессах прекращают действие.
Фоновое наблюдение действует только во время операции. Смена входа, сервера,
конфигурации, каталога, предпочтений или потеря связи отменяют прежний контекст.
Продолжение, восстановление и откат требуют отдельного явного действия.

Экран получает только проверенные локальные версии и годы, без путей, DLL или
receipt файлов. Запрос установки содержит код плагина и выбранные годы;
renderer не задаёт папку, доверенный сертификат, раскладку или план записи.
Для установки main заново проверяет наличие выбранного Revit.

## Реальные ограничения допуска

**Доверенный издатель и раскладки реальных пакетов пока не утверждены.**
Production factory остаётся закрытой до загрузки и создания staging.
Отметка verified сервера не заменяет подпись DLL. Подписи тестового runtime,
тестовые раскладки и подставной signer oracle не считаются доверием бюро.
Автоматическая установка и массовая загрузка не включены.

Текущий сервер не возвращает актуальные метаданные произвольной прежней сборки.
Откат или восстановление скрытого из latest build блокируются; задание
[SERVER-PLUGINS-001](https://github.com/SchemaTools/schema-teams-desktop/blob/codex/task-exchange/tasks/SERVER-PLUGINS-001.md)
опубликовано отдельно. Серверный код не менялся.

При незавершённой или неопределённой операции staging сохраняется. После
отдельного восстановления старые staging без живого handle консервативно
остаются на диске; автоматическая сборка таких остатков пока не реализована.
Предел распакованного вывода одной операции не является общим лимитом
занятого места с архивами, XML и резервными копиями.

## Таймер и проверка

Завершение без сети через общий main entrypoint не меняет навигацию и не
создаёт команду таймера. При неудачном открытии не теряется предложение
проверить таймер после возвращения. Enter отправляет сообщение, Shift+Enter
переносит строку, как согласовано ранее.

Программные проверки используют временные каталоги, инертные DLL, локальный
HTTP и реальные read-only XML/WinTrust helpers. Они не заменяют эксплуатацию
на Windows 10/11 с подписанными плагинами и открытым Revit. Реальные Addins,
системное доверие, серверные данные и установленный клиент при этих проверках
не изменялись. Ручные строки Excel остаются незаполненными до проверки
пользователем; исходный clipboard-сбой R02 остаётся открытым.

Полный прогон: 1066 unit-тестов и 151 сценарий Electron. В настоящем Electron
отдельно проверен контроль полного потребления deflate-потока. После упаковки
122 затронутые проверки повторены для нативных helpers. После эквивалентной
правки записи C#-выражения и уточнения тестового пути прошли 160 затронутых
проверок; перепакованный XML-helper сверяется с этими проверенными байтами.

Подпись установщика, обновление Desktop и интеграция датчика заставки остаются
следующими этапами. Этот выпуск не закрывает всё ТЗ.
