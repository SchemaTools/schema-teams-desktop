## Реализовано в desktop

- Sandboxed preload выдаёт только `window.schemaDesktop.send/on`, только главному
  фрейму настроенного origin. Main проверяет окно, фрейм, URL и данные каждого IPC.
  Уведомление, меню и отдельные страницы таймера не получают серверный мост.
- До hello — «Нет связи». Несовместимая старшая версия — полоса обновления и работа
  только как окно. Навигация, падение renderer, выход и смена пользователя очищают
  состояние, окна и ожидающие подтверждения.
- Счётчики трея/панели задач, тема панели, луна фокуса, точка таймера, подсказка,
  состояние связи и собственное меню у трея.
- Страница решает группировку по минуте, quiet, собственные сообщения, открытый чат
  и сводку фокуса. Приложение дополнительно подавляет обычные notify в фокусе/offline.
- Щелчок и «Открыть» показывают окно и вызывают `navigate(link)` с исходной ссылкой
  на чат/сообщение. Замечание 13 из Д2 закрыто в реализации; ручное подтверждение
  на настоящем Teams ещё требуется.
- Enter отправляет, Shift+Enter переносит строку. Ответ ждёт результата страницы;
  ошибка сохраняет черновик. Повтор того же текста сохраняет requestId; серверный
  клиент страницы передаёт его как Idempotency-Key.
- «Прочитано» и «Начать работу» передают цели серверного уведомления. Меню передаёт
  фокус, паузу/продолжение. Выбор/окончание задачи открывает готовые серверные
  /desktop/pick и /desktop/finish в отдельном окне с той же сессией. API и расчёты
  остаются серверными; сценарии Д5 не считаются принятыми.
- Пункт «Уведомления» через внутренний адаптер preload нажимает существующий
  колокольчик `.nt > button[aria-haspopup="dialog"]`, если он закрыт. Отдельного
  маршрута уведомлений у сервера нет. Публичный договор не расширен; изменение
  компонента потребует сверки селектора.
- До Д4 openPath возвращает blocked. Настройки/обновление Д6 ещё не реализованы.
  enabled/sound/preview пока в локальных настройках; звук только при показе окна.
- Тайм-аут команды — 15 секунд. Сообщения, тексты ответов, результаты API и тексты
  исключений не записываются в журнал. Паролей/токенов и отдельного сокета у main нет.

## Замечание 16: системное «Не беспокоить»

27.10.2026 прочитан заполненный пользователем бланк Windows 10 (19045), сборка
0.1.0: **17 проверок пройдены**, пункт 16 не пройден — при включённом системном
режиме появились собственное окно и звук. Вход, реальный быстрый ответ, отсутствие
дублей, сохранение черновика, открытие нужного чата, группировка, фокус Teams,
таймер из назначения, меню, reconnect и выход подтверждены пользователем.
Оригинал Excel сохранён без изменений; его данные и адрес стенда в Git не включены.

Причина: один SHQueryUserNotificationState не определяет современный Focus Assist.
Для версии **0.1.1** добавлен независимый read-only запрос активного профиля WNF.
Окно и звук разрешаются только при `shell=5` и `focus=0`. Приоритетные, будильники,
ошибка и неизвестное состояние подавляют оба; счётчик остаётся. Формат ответа
helper версионирован: старый одиночный `5` больше не считается разрешением.
Источник, ABI и ограничения описаны в [native-notification-state.md](native-notification-state.md).
WNF не документирован Microsoft, поэтому Windows 11 по-прежнему требует проверки.
Новых npm-зависимостей нет.

Разрешение на показ больше не кэшируется на секунду: объединяются только запросы,
которые выполняются одновременно. Перед фактическим showInactive после загрузки
скрытого окна выполняется новая проверка. Выход, offline, фокус Teams или отключение
уведомлений за это время также предотвращают запоздалое окно и звук.

Во время работы пользователь последовательно подтвердил три режима в настройках
настоящей Windows 10. Helper вернул `focus=2` для «Только будильники», `focus=0` для
«Выключено», `focus=1` для «Только приоритетные»; в этих снимках `shell=2`. Настройки
менял пользователь, приложение и helper не содержат функций переключения.
Сверка обнаружения не подменяет повторную доставку настоящего сообщения в новой
установленной сборке. Пункт 16 на версии 0.1.1 ещё предстоит перепроверить.

| Проверка 0.1.1, 27.10.2026 | Итог |
|---|---|
| Полный npm run check на чистом снимке | Типы, ESLint, Prettier, 100 модульных и 31 сквозной тест пройдены |
| Реальная Windows 10, пользовательские переключения | Три UI-режима сопоставлены с focus 2/0/1; чтение read-only |
| Локальный стенд с настоящим helper | Окно и звук подавлены; при shell=2 и смене активного профиля 1→0 этот опыт не доказывает отдельное подавление DND и не засчитывается как ручная приёмка |
| Адресная сборка NSIS Windows x64 | 0.1.1 собрана, собственный helper включён; подпись — этап Д6 |
| Заполненный Excel 0.1.0 | Не изменён; новый отдельный бланк содержит 7 повторных проверок и пилот на 3 ПК |

## Проверки и приёмка

Автотесты используют локальную HTTP-страницу с настоящим публичным протоколом,
реальными preload/IPC и Electron. Они не запускают серверный backend и не
доказывают доставку в настоящий Teams. Проверяются версия/валидация, опасные
ссылки, iframe/чужой origin, счётчики, offline/reconnect, фокус/выход, точные цели
команд, черновик/requestId повторного ответа, меню и изоляция страниц таймера.

Снимок уведомления просмотрен. Захват меню через Playwright и Electron capturePage
зависал; фактическая видимость нативного окна и его команды проверяются отдельно.
Это не считается успешным снимком меню.

| Проверка 23.10.2026 | Итог |
|---|---|
| Полный npm run check на чистом снимке индекса | Типы, ESLint, Prettier, 59 модульных и 25 сквозных тестов пройдены |
| Первый полный прогон на чистом снимке | 22/25: тесты не учитывали смещение монитора и наведение физического курсора; меню проверялось до первого показа главного окна. Исправлены условия тестов; итоговый прогон выше |
| Захват меню | Playwright/capturePage — тайм-аут; успешный снимок не получен, видимость/команды проверены отдельно |
| GET health и публичной страницы стенда | Доступен, Teams 0.11.2, веб-скрипт содержит schemaDesktop; вход и изменения данных не выполнялись |
| NSIS Windows x64 | Адресная пробная сборка создана, эксперимент выключен, helper упакован; подпись остаётся Д6 |
| Новая таблица ручной проверки Д3 | 18 сценариев Windows 10, все «Не проверено»; исходный заполненный Excel Д2 не изменён |

Полный check запускался на чистом снимке, поскольку в рабочей папке есть отдельный
неотслеживаемый прототип, который не относится к desktop и попадает в общий поиск
линтера. Исходники/тесты снимка совпадают с индексом; проверки не отключались.
