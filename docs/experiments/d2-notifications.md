# Опыт Д2: уведомления Windows с полем ответа — памятка

ТЗ, 5.1. Проверяем, работают ли **родные** уведомления Windows с полем ответа и кнопками. Пройти на одном компьютере с Windows 11 и на одном с Windows 10. Время — около 15 минут.

## Подготовка

1. Запустить `Schema Teams Notify Test 0.1.0.exe`. Установка идёт сама, без вопросов; окно приложения покажет «Пробная сборка: проверка уведомлений».
2. Найти значок Schema Teams у часов (квадрат, разделённый по диагонали). Если его не видно — стрелка «^» у часов.
3. Все проверки запускаются так: **правой кнопкой по значку → «Проверка уведомлений» → пункт**.
4. Где отвечать: в поле «Ответить…» внутри уведомления ввести слово **проверка** и нажать Enter (или кнопку отправки рядом с полем).
5. Центр уведомлений: Windows 11 — `Win + N` или щелчок по часам; Windows 10 — `Win + A`.

После каждой проверки записать в таблицу внизу, что увидели. Если что-то пошло не так — это тоже итог, просто записать.

## Проверки

| № | Что сделать | Что должно получиться |
|---|---|---|
| 1 | Открыть окно (щелчок по значку). Пункт **1**. Ответить «проверка». | Уведомление с полем ответа и кнопками «Открыть», «Прочитано». После Enter — короткое «Отправлено в «Иванова И.И.»». |
| 2 | Закрыть окно крестиком. Пункт **2**, подождать 15 секунд. Ответить «проверка». | То же, что в 1, при спрятанном окне. |
| 3 | Пункт **1**, ничего не трогать — уведомление уйдёт само. Через минуту открыть центр уведомлений и ответить оттуда. | Ответ из центра уведомлений проходит, приходит «Отправлено…». |
| 4 | Пункт **1**, дать уйти в центр уведомлений. Правой кнопкой по значку → **«Выход»**. Открыть центр уведомлений и ответить. | Приложение запускается само, приходит «Отправлено в «чат»». |
| 5 | Пункт **3** — нажать **«▶ Начать работу»**. Ещё раз пункт 3 — нажать **«Открыть»**. | Обе кнопки видны и нажимаются; «Открыть» показывает окно. |
| 6 | Включить «Не беспокоить» (Windows 11: центр уведомлений → колокольчик; Windows 10: центр уведомлений → «Фокусировка внимания» → «Только будильники»). Пункт **1**. Потом выключить «Не беспокоить». | Всплывающего уведомления нет, но в центре уведомлений оно есть. |
| 7 | Пункт **5** (длинный текст). Ответить «проверка». | Текст читается (может быть обрезан с «…»), поле ответа и кнопки на месте. |
| 8 | Пункт **6** (три подряд), затем пункт **4** (два сообщения одного чата). | Три уведомления видны (стопкой или по очереди). Во втором случае в центре уведомлений от «Сидоров С.С.» — **одно**, второе заменило первое. |

## Что сохранить

- Таблицу ниже — заполненной.
- Файл итогов `%APPDATA%\Schema Teams\toast-experiment.jsonl`: правой кнопкой по значку → «Проверка уведомлений» → «Открыть файл итогов». Скопировать его в папку проекта на Диске под именем `toast-experiment-<Windows 10 или 11>.jsonl`. В файле нет текстов ответов — только время, нажатые кнопки и длина ответа.
- Снимок экрана уведомления с полем ответа (`Win + Shift + S`) — по желанию.

После опыта пробную сборку удалить: «Параметры → Приложения → Schema Teams → Удалить».

## Вторая сборка (22.10.2026)

Поправки по итогам Windows 10 (`docs/decisions.md`, 22.10): регистрация в установщике, постоянный код активатора, отброс повторов, своё уведомление с «Отправить» и группой чата, запуск из уведомления без окна. Проверки — на Windows 10 и Windows 11:

| № | Что сделать | Что должно получиться | Windows 10 |
|---|---|---|---|
| А | Пункт **1**. Ответить «проверка» через Enter, ещё раз — стрелкой «Отправить». | Всплывает без правки реестра; на каждый ответ — одно «Отправлено…» | всплывает — да; ответы — **не проверено** |
| Б | Пункт **4**, затем Win + A. | Сообщения под заголовком «Сидоров С.С.», уведомление одно | показ — да; группа — не подтверждена |
| В | Пункт **1**, дать уйти в центр; значок → «Выход»; ответить из центра. | Значок появился, окна нет, «Отправлено…»; в журнале запуск `fromNotification: true` | **не проверено** |
| Г | Сразу после В: пункт **3** → «Открыть». | Открывается окно | **не проверено** |

Отброс повтора на второй сборке подтверждён: «▶ Начать работу» — одно действие, второе нажатие с пометкой `repeat`.
