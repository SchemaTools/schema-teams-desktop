# Schema Teams Desktop 1.0.0 — первый выпуск для бюро

Настольное приложение Schema Teams живёт у часов Windows и даёт то, чего нет
в браузере.

**Чаты.** Чаты объектов и личные чаты в своём окне: папки «Все / Объекты /
Личные / События», ответы и цитаты, реакции, стикеры и эмодзи бюро, вложения
и фото из буфера обмена, поиск, сведения о чате по щелчку на шапку. Фото
профиля сотрудников. Светлая и тёмная тема.

**Уведомления.** О сообщениях, @упоминаниях и задачах — с быстрым ответом
прямо в уведомлении, кнопками «Открыть» и «Прочитано». Учитываются «Фокус»
и тихие часы из настроек Teams. Утренняя сводка дня.

**Учёт времени.** «Начать работу / Закончить работу» в окне и в меню у часов.
Пауза при блокировке компьютера — для таймера, запущенного на этом компьютере.
Напоминание в 18:30 по времени бюро, проверка записи перед сохранением.

**Сетевые папки.** Пути `\\сервер\…` из чата открываются в Проводнике.
К серверам не из списка бюро приложение обращается только после вашего
подтверждения.

**Плагины Revit.** Проверенные сборки бюро ставятся и обновляются сами, когда
Revit закрыт. Хранится предыдущая версия — кнопка «Вернуть» у плагина.

**Новая версия приложения.** Приложение само проверяет, скачивает подписанную
сборку бюро и предлагает установить; черновики сообщений не теряются.

Если что-то работает не так — меню → «Сообщить о проблеме».
