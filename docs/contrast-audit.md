# Контраст текста 0.6.7

Требование ТЗ v4, раздел 2.5: контраст текста не ниже 4,5:1 в обеих темах.
Автоматическая проверка упакованной 0.6.6 подтвердила отклонение в светлой теме:
подпись служебного чата `#707579` на фоне группы `#e8ecfb` имела отношение
3,952:1. В 0.6.7 общий цвет второстепенного текста стал `#555d64`:
на том же фоне отношение 5,683:1. Цвет подсказок полей теперь также задан
переменной темы с непрозрачностью 1. Подпись под вводом использует основной
цвет текста, чтобы проходить и консервативную границу наложения узора.
Размеры и расположение элементов сохранены.

## Повторение

`tests/e2e/contrast.spec.ts` запускает настоящий Electron с отдельным профилем
и локальным сервером-фикстурой. Проверяются обе темы: до входа, чат с сообщениями,
служебное событие, сведения об объекте, пять вкладок настроек, форма диагностики,
выбор задачи таймера, отдельное окно трея и четыре шага первого запуска.
Отдельно проверяется настоящее окно уведомления до и после быстрого ответа.
Все бизнес-запросы направлены только на фикстуру.

Для обнаружения отклонений используется devDependency `axe-core` 4.14.0
(MPL-2.0). В правило `color-contrast` явно передано требование 4,5:1 для обычного
и крупного текста: стандартный порог WCAG для крупного текста ниже требования ТЗ.
Код анализатора внедряется только в тестовые страницы. CSP приложения не ослаблена,
анализатор не включён в установленное приложение.

Каждый проход сохраняет в Playwright attachments три разных списка: подтверждённые
нарушения, пройденные узлы и `incomplete`. Неопределённый результат не считается
прохождением. Частично перекрытый текст, короткие инициалы и сложные градиенты
требуют дополнительной оценки. Для нынешних градиентов добавлен отдельный
консервативный расчёт по вычисленным стилям: все шесть цветов аватаров,
подпись под полем ввода и разделитель дня. Для фона чата используются поканальные
границы четырёх цветов и затемнение верхним узором. Прозрачность штриха 6,5%
считывается из SVG, при расчёте предполагается наложение всех его фигур
в одном пикселе; это консервативная граница. Для разделителя учитывается
также прозрачность его подложки. При изменении устройства фона метод нужно пересмотреть.

Проверка подтверждает контраст показанных состояний на тестовых данных.
Она не удостоверяет весь WCAG, все возможные вложения/состояния или удобство
на конкретном мониторе. Ручная проверка двух тем на Windows 10/11 остаётся
в общей Excel-книге незаполненной.

Метод расчёта относительной яркости и исключения для неактивных контролов:
[W3C, Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).
Устройство настройки и результатов анализатора:
[axe-core 4.14.0 API](https://github.com/dequelabs/axe-core/blob/v4.14.0/doc/API.md).
