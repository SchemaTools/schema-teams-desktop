# Проверяемый блок 0.10.0 — каталог плагинов

Этапы 1–2 Д5 используют договор Teams 0.12.1-b. В существующем разделе
«Плагины» доступны каталог, версии и каналы сборок, годы Revit, зависимости
и «Что нового». Сохранён вид утверждённого экрана: сводка, карточки и настройки
с Lucide. Пустой каталог не выдаётся за успешную установку. Для обнаруженных
локальных .addin без записи управляемой установки версия неизвестна.

Каталог читается после входа, раз в шесть часов, по кнопке «Проверить» и после
desktop:plugins. Событие сразу исключает прежние данные из отображаемого каталога;
повторные события объединяют перечитывание. Ответ другого входа или сервера
не возвращает старый каталог. Отсутствующая capability и отказ прав имеют
отдельное честное состояние. Рабочая сборка должна быть verified, пробная
доступна только испытателю с локальным согласием для текущих сервера и пользователя.
Отзыв роли испытателя немедленно отключает пробный канал.

В main реализован план зависимостей по числовым X.Y[.Z], отдельно для выбранных
2025/2026. Цикл, неизвестная локальная версия зависимости, отсутствующая или
несовместимая сборка блокируют план. Из Desktop API берутся только действующие
известные ID: история admin API и выдуманные прежние версии не используются.
План не является доказательством ABI-совместимости или разрешением установки.

Отдельный потоковый загрузчик main ограничен 200 МиБ: свой сервер, точный
/api/desktop/plugins/files/id, cookie, запрет redirect, exclusive .part,
инкрементальные размер и SHA256, точное сравнение метаданных/Content-Length/байтов,
отмена и очистка своего staging при ошибке. Бинарные данные и пути назначения
не принимаются через IPC. Локальные тесты используют временные каталоги и HTTP;
живые пакеты бюро ради проверки не скачиваются.
Проверка каталога и загрузчик записывают фиксированные этап и результат в журнал,
без описаний изменений, адресов, путей или хешей файлов.

## Закрытый допуск установки

**Установка недоступна: доверенный издатель не настроен.** Отметка verified
сервера и SHA256 архива не подтверждают подпись DLL. Настройку автообновления
можно сохранить, но она не запускает загрузку или установку. Кнопки установки
заблокированы; массовой и фоновой загрузки архивов нет. Загрузчик и планировщик
пока проверяются как внутренние компоненты на локальных fixtures.

Следующий блок 0.11 — этапы 3–4: безопасная ZIP/manifest policy, настоящий
Windows verifier, транзакция, crash recovery и rollback в временных каталогах.
Распаковка, подпись, размещение в Addins и запуск Revit в 0.10 не реализованы
и не считаются проверенными. Production admission дополнительно требует
публичного publisher pin, подписанных актуального и прежнего пакетов, схемы
размещения и контролируемой совместимости Revit 2025/2026. Системное доверие,
настоящие DLL, Addins и модели не менялись.

Ручная приёмка Д5, подпись установщика, реальные события Windows и исходный
clipboard-сбой R02 остаются открытыми. Предыдущие CAS/durable timer, Д4 и
неизвестный исход обращения поддержки сохраняются; этот блок не закрывает всё ТЗ.
