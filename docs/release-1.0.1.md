# Schema Teams Desktop 1.0.1 — знак бюро и плитка в «Пуске»

**Значки по логотипу бюро.** Приложение, панель задач, меню «Пуск», уведомления
и значок у часов — знак Schema «Пересечение»: два контурных квадрата. У часов
значок белый на тёмной панели задач и графитовый на светлой.

**Плитка в «Пуске».** Windows не разрешает программам закреплять себя
в «Пуске», поэтому в мастере первого запуска и в настройках («Общие») появилась
подсказка: кнопка «Показать ярлык», затем правой кнопкой по ярлыку →
«Закрепить на начальном экране».
