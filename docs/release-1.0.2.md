# Schema Teams Desktop 1.0.2 — новый чат, «в сети» и набор плагинов Revit

**Новый чат.** Кнопка «Новый чат» над списком чатов: личный чат с коллегой
или группа с названием. Поиск коллег по фамилии.

**Кто в сети.** Зелёная точка у аватара коллеги в сети — в списке чатов,
в шапке личного чата («в сети» или «был(а) в сети в …») и в сведениях о чате.

**Плагины Revit через приложение.** Набор плагинов Schema ставится
и обновляется сам, когда Revit закрыт; галочками можно выбрать, какие плагины
нужны. Прежний установщик плагинов приложение удалит само и сохранит
настройки бюро. При первой установке Windows спросит про сертификат бюро —
нажмите «Да».

**Значок в «Пуске»** обновляется при каждой установке приложения.
