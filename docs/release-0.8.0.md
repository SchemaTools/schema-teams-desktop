# Проверяемый блок 0.8.0 — Д4 и Lucide

Договор — Teams 0.12.1-b, shared-типы и ответы SERVER-CHAT-001; новый мост и
новый вход не вводятся. Этот блок не означает завершение всего ТЗ или ручной приёмки.

Быстрые реакции идут в порядке 👍 ❤️ 🔥 ✅ 👀 🎉. «Ещё» открывает прежние
😂 и ❓; уже поставленные реакции всех восьми видов остаются видимыми.
Fluent Emoji 3D поставляются локально с происхождением и MIT-лицензией.
Изменение подтверждается API; повтор во время запроса и ответ прежнего входа
не меняют текущие реакции.

Список использует серверные myActiveTasks и top. Личное закрепление чата
отдельно от закрепления сообщения: максимум пять, шестой отказ отображается
без ложного закрепления. Внутри закреплённых порядок по последнему сообщению.
Остальные чаты сохраняют группу требующих ответа; объекты с моими активными
задачами выделены по собственному ID и счётчику сервера. Отсутствующие/null
поля старого сервера остаются неизвестными, закрепление недоступно.

album_issued и remarks_closed имеют отдельные карточки. Праздничный эффект
относится только к проверенному live album_issued с совпадающими kind/id,
ограничен по времени и отключён при reduced motion. История и неизвестные
виды событий не запускают его; тип не выводится из текста уведомления.

Socket quiet подавляет popup, сохраняя непрочитанное и обновление истории.
Локальная проверка тихих часов использует пояс бюро из config. Упоминание
не дублируется обычным popup сообщения. История после reconnect не служит
источником popup. Отдельная граница принятой истории и точные seen-ID
сохраняют новые события при доставке не по порядку. Cache ограничен 4096 ID
на тип: при переполнении popup закрыт до свежего снимка, покрывающего
пропущенные ID; непрочитанное и история продолжают обновляться.

Lucide React закреплён на 1.54.0, React остаётся 18.3.1. Renderer использует
именованные импорты с tree shaking; native popup — доверенные локальные
X/Send SVG того же пакета. Полная ISC-лицензия и Feather MIT входят в сборку.
Знак Schema и Fluent PNG не заменяются. Проверки контраста включают новые
stroke-значки и обе темы; incomplete-узлы не считаются прохождением.

Проверки выполняются на локальных HTTP/Socket.IO стендах: типы, lint/format,
unit и полный Electron-набор. Подробные команды, хэши и установщик остаются
локальными доказательствами выпуска. Реальный сервер не изменяется.
Проверка реальных Windows shutdown/lock, установки и исходного clipboard
сбоя R02 остаётся открытой. Следующий программный блок — Д7, затем Д5.
