# Статус приёмки Desktop 1.0 — 05.11.2026

Сверка со сценариями раздела 16 ТЗ v4 на ветке `fix/pr6-review` (версия 0.14.0).

**Коротко для руководителя.**

- **Можно попробовать руками** (с тестовым сервером Teams): вход, чат, вложения, реакции, служебный чат, путь `\\сервер\…` («Показать в папке»), уведомления и быстрый ответ, «Фокус», тема, таймер с паузой при блокировке, напоминание 18:30, утренняя сводка, «Сообщить о проблеме», настройки.
- **Нельзя попробовать по-настоящему**: установку плагинов Revit и установку новой версии приложения — список доверенных сертификатов пуст, поэтому оба действия честно отказывают («доверенный издатель не настроен»).
- **Руками на Windows не проверено ничего из нынешней сборки.** Есть только ручной опыт Д2 на Windows 10 от 22.10 — на прежней сборке, до ТЗ v4. Windows 11 и Revit не проверялись совсем.
- **Нужны решения:** (1) сертификат бюро и SHA-256 для списков доверия плагинов и обновлений; (2) делить ли PR #6 на части; (3) когда пробная сборка на 3 компьютерах (ТЗ 14); (4) память: 480 МиБ в 0.6.5 и 378 МиБ в 0.6.6 без Revit против порога 400 — принять или искать дальше; (5) делить ли `clientHost.ts` (около 3500 строк) на модули.

Обозначения: **да** — есть; **частично** — есть часть сценария; **нет** — нет; **—** — к сценарию не относится. «Сквозной тест» — Playwright `_electron` против заглушки сервера, а не настоящий Teams.
