## Сверка серверных зависимостей 29.10

- В `0.11.2-b` по-прежнему шесть реакций; поля персонального закрепления
  и моих задач в ChatSummary отсутствуют. В регистрации app и exports shared
  нет реестра плагинов. Серверный код Desktop не изменяет.
- У `GET /api/objects` есть `ObjectCard.myTasks`, но только для сотрудников
  без `see_all`; руководителю приходит null. По этому полю можно безопасно
  сопоставлять объект по ID, однако оно не даёт общего решения для всех ролей.
  Не сопоставлять задачи и объекты по названию; null не считать нулём.
- Полный Д4 и Д5 не закрывать по отсутствию ручных испытаний или серверного API.

## Проверка каждого готового блока

Типы, линтер, необходимые модульные и сквозные тесты; визуальная проверка обеих тем.
Из-за посторонних локальных проектов запускать общий check на чистом снимке
исходников, не ослабляя правила линтера. Перед push — проверка приватных данных.
Установщик собирать с прежней приватной конфигурацией стенда. Проверить версию,
содержимое asar и фактическую подпись. Обновить статус, PR #6 и общую Excel-книгу.
