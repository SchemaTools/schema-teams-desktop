Обновлено 30.10.2026. Работа ведётся в `codex/v4-client`, PR #6; основа — ТЗ v4.
Серверный репозиторий доступен только для чтения. Реальные адреса, установщики,
Excel и журналы остаются локально, вне публичного Git.

  результаты сохранены; Windows 11 отложена пользователем.

  переход к новым сообщениям, эмодзи, группировка автора.
- Д4, 0.4.4: сведения об объекте, роли/стадии/пути и переход на сайт,
  адаптивная панель; разные виды служебных событий и подписи сроков.
- Д6, 0.5.0: собственный ручной таймер, выбор/поиск и недавние задачи, карточка

  карточка существующего серверного утреннего события `timer_stopped`.
- Д7, 0.6.0: собственное окно настроек, автозапуск/тема/popup/звук/текст,
  вкладка учёта времени, версии и папка журналов. Запись настроек атомарна;
  при сбое сохранённое состояние не заменяется. Тестовые профили исключены
  из регистрации Windows startup, в том числе у упакованного EXE.
- Д7, 0.6.1: проверка опубликованной версии при запуске, раз в шесть часов
  и вручную. Баннер/трей, «Что нового» обычным текстом и «Позже» до перезапуска.
  Манифест проверяется в main; загрузки и установки ещё нет. Стенд ответил
  `404 no_release`: администратор пока не опубликовал сборку.
- Д7, 0.6.2: адрес и «Проверить связь» в общих настройках; подключение сборки
  без адреса. Применение требует свежей успешной проверки и подтверждения закрытия
  несохранённых данных. Старые окна/запросы закрываются, данные входа очищаются;
  новый сервер получает отдельный постоянный профиль входа. Дальнейшие шаги
  первого запуска добавлены в 0.6.3.
- Д7, 0.6.3: четыре шага первого запуска — подключение, вход, сведения
  о стандартных папках Revit 2025/2026 и готовность/автозапуск. Старый профиль
  продолжает работу, повторный мастер доступен в общих настройках. Установка,
  версии и подписи плагинов по-прежнему требуют серверного реестра и сертификата;
  файлы .addin не выдаются за подтверждение загрузки плагина.

## Сверка серверных зависимостей 29.10

- В `0.11.2-b` по-прежнему шесть реакций; поля персонального закрепления
  и моих задач в ChatSummary отсутствуют. В регистрации app и exports shared
  нет реестра плагинов. Серверный код Desktop не изменяет.
- У `GET /api/objects` есть `ObjectCard.myTasks`, но только для сотрудников
  без `see_all`; руководителю приходит null. По этому полю можно безопасно
  сопоставлять объект по ID, однако оно не даёт общего решения для всех ролей.
  Не сопоставлять задачи и объекты по названию; null не считать нулём.
- Полный Д4 и Д5 не закрывать по отсутствию ручных испытаний или серверного API.
