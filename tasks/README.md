# Обмен заданиями

Ветка `codex/task-exchange` в `schema-teams-desktop` предназначена для постановок и ответов между ответственными за Desktop и сервер Schema Teams. Рабочий код остаётся в отдельных ветках соответствующих репозиториев. Создание этой ветки не разрешает менять сервер от имени автора Desktop.

| ID | Задание | Статус |
|---|---|---|
| SERVER-D5-001 | [Безопасное управление таймером из Desktop](SERVER-D5-001.md) | ТЗ подготовлено для передачи ответственному за сервер; реализация не заявлена |
| SERVER-CHAT-001 | [Что нужно серверу для собственного чата Desktop (макет v4)](SERVER-CHAT-001.md) | Редакция 2 по ТЗ v4 и макету v4 — задание для согласования ответственным за сервер; реализация не заявлена |

## Как обмениваться

1. Одна постановка — один файл `tasks/<ID>.md` со статусом, требованиями и критериями приёмки.
2. Уточнения согласовываются в этом файле; изменение требований не считается реализацией.
3. Исполнитель делает код и тесты в своём репозитории и своей рабочей ветке.
4. Результат оформляется отдельным файлом `tasks/replies/<ID>.md`: ветка/commit/PR, что сделано, изменения договора/API, миграции, выполненные проверки и оставшиеся ограничения. Для SERVER-D5-001 также нужны новый shared-файл, его source commit/blob SHA и порядок совместимого выпуска.
5. После проверки на стенде заказчик фиксирует приёмку в постановке. Открытый пункт или неподтверждённый тест не помечается выполненным.

В эту ветку не добавляются установщики, заполненные пользовательские таблицы, журналы, адреса стендов, учётные данные и секреты. Ответственный за сервер не должен менять desktop-код: новый договор передаётся разработчику Desktop для отдельной интеграции.
