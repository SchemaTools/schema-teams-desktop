# Schema Teams Desktop

Настольное приложение для Windows 10/11 к системе управления проектами Schema Teams: значок в трее со счётчиком, всплывающие уведомления с быстрым ответом, открытие сетевых папок из чата, кнопки «Начать работу / Закончить работу» для учёта времени.

- ТЗ v4 — [`docs/tz/2026-10-25 — ТЗ Schema Teams Desktop 1.0_v4.md`](<docs/tz/2026-10-25 — ТЗ Schema Teams Desktop 1.0_v4.md>)
- Серверный API — [`docs/server-api.md`](docs/server-api.md)
- Интерактивный макет — `docs/mockups/` (открыть в браузере)
- Решения — [`docs/decisions.md`](docs/decisions.md)

Статус этой ветки: собственный клиент **0.6.3** по ТЗ v4 — чат с файлами,
реакциями, поиском и сведениями объекта; ручной таймер, напоминания и собственные
настройки приложения, версии, папка журналов, проверка доступного обновления
и мастер первого запуска с проверкой связи, входом и чтением стандартных папок Revit.
Вход открыт отдельно, API и Socket.IO работают в main. Это предварительная сборка:
полная приёмка Д3/Д4/Д6 ещё не завершена; автопауза требует серверной доработки.
Состав, проверки и ограничения — [`docs/v4-client-status.md`](docs/v4-client-status.md).
Команды — в [`CLAUDE.md`](CLAUDE.md).
